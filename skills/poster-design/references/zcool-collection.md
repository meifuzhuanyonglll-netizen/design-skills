# 站酷《排版设计》逐篇索引

[木本鱼鱼的收藏夹](https://www.zcool.com.cn/collection/ZNjI5Nzk4MA==)共 21 篇。已复核全部原文页面、正文长图与案例图。下表记录每篇迁移到海报制作的要点。案例尺寸、字号倍数、颜色搭配及修图软件参数随原稿而定。

| 序号 | 文章 | 可用到海报的做法 |
| --- | --- | --- |
| 1 | [自学平面设计，快速入门教程（3/5）· 排版构成篇](https://www.zcool.com.cn/article/ZNTUxMTYw.html) | 用距离表达归属，留白分隔内容，对齐建立秩序，对比建立阅读顺序，重复样式帮助识别同类信息。请柬与图表案例示范了不同媒介里的同一原则。 |
| 2 | [山岩 PS 方法技巧小讲堂 · 第二十三弹](https://www.zcool.com.cn/article/ZMzk5Njk2.html) | 用框分隔真实的信息组。让大小、粗细和明度承担标题与说明的差别。外文如承担装饰角色，要服从阅读顺序。叠字优先解决背景与字的明暗区分。 |
| 3 | [山岩 PS 方法技巧小讲堂 · 第二十一弹](https://www.zcool.com.cn/article/ZMTY3MTk2.html) | 按主图、文案量和气质选中心、中轴、分割、倾斜、网格化或满版构图。鞋款案例可通过改变景别及留白，在保留主体的同时改变视觉重心。 |
| 4 | [山岩 PS 方法技巧小讲堂 · 第十九弹](https://www.zcool.com.cn/article/ZMTU0NzE2.html) | 场景合成先定叙事和主体，再安排承托面与主体后方的环境，核对透视、大小和角度。用统一色调、光影和局部质感把素材融在一起。 |
| 5 | [山岩 PS 方法技巧小讲堂 · 第十八弹](https://www.zcool.com.cn/article/ZMTUwNDYw.html) | 合成可用有意义的遮挡、投影和拼贴三种手法。投影应跟随光向和承托面，贴近物体的阴影与更远的虚影分别处理。风格化拼贴要维持元素之间的视觉关系。 |
| 6 | [山岩 PS 方法技巧小讲堂 · 第十六弹](https://www.zcool.com.cn/article/ZMTQyNDky.html) | 按主题选择近似色融合、互补色反差或明暗分离。主体过轻时，可先试放大、选细节裁切、调整明度或组织成群。是否裁切由产品识别点与任务判断。 |
| 7 | [山岩 PS 方法技巧小讲堂 · 第十七弹](https://www.zcool.com.cn/article/ZMTQzMzcy.html) | 标题与副文案先在共同边界内成组，再用大小、字重、松紧或颜色做对比。点、线、面和实体装饰可从一套形状变体发展，散落元素可用大小、角度及虚实变化形成节奏。 |
| 8 | [基础排版三大招！](https://www.zcool.com.cn/article/ZMTEwNDE2.html) | 依据文本用途选择对齐方式。分别控制图片和文字的视觉跳跃率，即主要与辅助元素之间的尺度反差。特写配全景可建立图片主次，字号差帮助文字快速扫读。 |
| 9 | [版式設計中的文字层級理论](https://www.zcool.com.cn/article/ZNTQ3MDE2.html) | 先分析文本的重要性，再组合字族、字重、字号和线条。组内和组间用不同间距表达层级，并用版面实际显示情况校验。案例的字号倍数可用于练习建立一致节奏。 |
| 10 | [PPT-文字排版也能高大上](https://www.zcool.com.cn/article/ZMTQxMzM2.html) | 文本为主时可用字号、色彩、刻意安排的留白或字形塑造画面。色块分隔内容，图标标识主题，编号用于真实的步骤或顺序。 |
| 11 | [跟着世界杯的节奏玩版式①如何做出层次感](https://www.zcool.com.cn/article/ZODQzOTI=.html) | 先拉开主体图与主文案的大小关系，再用有意义的小元素补充细节。案例用明显的多级尺度组织图、文字与点状信息，控制对比出现的次数。 |
| 12 | [跟着世界杯的节奏玩版式②如何做出版式的空间感](https://www.zcool.com.cn/article/ZODU1MTY=.html) | 用主体周围的留白、颜色进退或置入实景建立空间。主体缩小能增加周边的空间感，也会改变其冲击力。可按项目同时使用几种方法。 |
| 13 | [一张照片如何排版？](https://www.zcool.com.cn/article/ZMTExMDY4.html) | 同一张图可通过裁切、图文绕排、文案图形化和二次加工改变结构。先保证全局层级，再让字与图的边缘、方向、色调或形状相互关联。 |
| 14 | [主体——版式设计的第一步](https://www.zcool.com.cn/article/ZMTEyODQ0.html) | 从文案筛选一级和二级主体，依次用位置、尺度、元素呼应及颜色刻画。案例把同一套文案换成不同主角，示范主体选择如何改变构图。 |
| 15 | [平面设计的留白技巧](https://www.zcool.com.cn/article/ZMTcwNzk2.html) | 可从低干扰背景、清楚的图像主体和简洁文字组分别调整留白。重度留白有利于气质表达，原稿依赖场景传达情绪或文化信息时要检查删减的代价。 |
| 16 | [照片 VS 图形——照片和图形在设计中的区别与应用](https://www.zcool.com.cn/article/ZMTg0ODAw.html) | 照片便于表现真实、质地与信任，图形和文字图形化适合表达概念或艺术气息。茶具案例用同一产品做了实景、字形和纯图形处理。 |
| 17 | [设计中的抄袭与逆袭](https://www.zcool.com.cn/article/ZNDg5NTEy.html) | 从参考中拆解色彩角色、构图、字体关系与网格。用当前素材和文案重新构建，例如先把参考网格化为方块，再用同一网格试多个结构。 |
| 18 | [浅谈网格系统](https://www.zcool.com.cn/article/ZNDk3OTEy.html) | 按内容设定版心、栏宽、栏距与基线。通栏、等分栏、比例栏及模块网格按信息密度选用。主体可以有意跨栏或出血，其他元素继续依照有用的参照线。 |
| 19 | [提高设计档次的 8 个方法](https://www.zcool.com.cn/article/ZNTExNDky.html) | 检查三类字体问题（数量、字形、效果）、三类图像问题（清晰度、系列统一、表现力）和两类色彩问题（颜色数量、主色调）。可从主图取色并为强调色分配角色。 |
| 20 | [版面太平了，怎么破？](https://www.zcool.com.cn/article/ZNTI2MDQw.html) | 用位置和尺度、光影虚实、色彩进退建立纵深。遮挡和透视帮助空间成立，阴影方向与透视消失点要一致。较平面的画面可用于需要安静、直接表达的任务。 |
| 21 | [为什么版式都是别人家的好——版式平衡篇](https://www.zcool.com.cn/article/ZNTU0OTk2.html) | 按视觉重量组织对称、非对称和多区块布局。用对角线、S 形或隐含几何轮廓组织信息，让人物视线或动作指向文案。样例通过调节色块和空白平衡重心。 |
