# 按问题改稿

以下是将已阅原则转成制作选择的工作建议。逐篇来源见[收藏逐篇索引](zcool-collection.md)。

| 看到的问题 | 先试的改法 | 怎么验证 |
| --- | --- | --- |
| 标题和数字都醒目，却不知道主旨 | 决定两者是同一组还是先后阅读。属于同一组时靠近并共享轴线。需要先后时压低次项的字重或明暗对比。单位与数字一起移动。 | 缩小后能读出“这是什么数字”，并能继续找到日期或条件。 |
| 字很多，每一组都像浮在画面上 | 先按意义分组，再统一各组的起始边和间距。保留用途所需的信息，长文优先按中文语义重断行。信息模块多时再引入分栏。 | 遮住背景图后，仍能看出哪些项目关联、先读哪组，以及哪里可行动。 |
| 留白很多，关键信息仍显挤 | 把空白调整到主体周围和相邻组之间。减少文字背后的高频纹理，必要时另设版心。促销或喜报可以保留高能量的边缘装饰，同时让焦点周边安静。 | 保持同一观看尺寸，对照调整前后，检查主区是否容易扫读且氛围仍符合任务。 |
| 只有一张照片 | 根据素材试三种关系中的一种或几种。干净的负空间可以铺图叠字，主体细节重要或画面杂时可切成图文对页式区域，主体能干净分离时可单独抠出进入新背景。选择能保住识别点、朝向和文字空间的裁切。 | 实际比例下，脸、产品边缘及必要的标志仍完整可辨。叠字有稳定的局部明暗对比。 |
| 画面太平或合成感重 | 需要空间感时，先试尺度差、局部遮挡或有透视的素材。只让辅助层级退入背景。涉及照片合成时，匹配光向、色温、接触阴影、锐度和边缘。保持关键文字和产品细节完整。 | 缩小看前后关系，放大看抠图边缘、悬浮感和光向。信息型极简海报可保留平面表达。 |
| 左右重量不均或视线出画 | 先看素材朝向和最重色块。移动文字组、调整面积、压低重区对比或收拢周围空白。对角线和 S 形可用于串联内容，选择跟实际阅读方向一致的路径。 | 看缩略图时眼睛能从主视觉转向信息区，边角没有意外的第二焦点。 |
| 同一套图看起来各做各的 | 复用标题关系、共同边距、标志锚点和强调色角色。换尺寸时重新安排组块，按新裁切验证。 | 并排看各版，气质与信息入口一致，每张图都能独立读懂。 |

## 常做的海报

- **内部喜报**：单一结果优先。无上下文看图，也应知道是谁取得了什么成果。若强调金额、数量或达成率，把单位与统计口径放在对应数字附近。用群消息预览验证。
- **直播封面**：先看直播主题与最重要的利益点能否在卡片里出现。合作品牌标记、产品和行动信息各有位置。实际平台容易遮挡的边角避开关键字。
- **产品宣传**：让真实产品的轮廓、标记和必要结构承担识别。先决定第一眼是产品还是卖点，再决定留白与图文位置。背景光效和纹理只做衬托。
- **活动招募**：活动名称建立入口，把同一次活动的日期地点排在一起。可报名时安排清楚的入口和说明。海报有议程时，可用网格分组，确保信息按顺序可读。

## 需要更换构图时

| 场景 | 可先试的构图 | 需要检查的地方 |
| --- | --- | --- |
| 单一主体、短文案 | 中心型集中视线。要突出产品细节或现场沉浸感，可试大图满版。 | 满版前检查裁切会不会丢掉识别点，文字是否有干净落点。 |
| 典礼、公告或强调稳重 | 中轴或对称。可让从主标题到辅助信息的组块宽度逐步收拢。 | 拉开主次，看视觉重心与阅读顺序是否一致。 |
| 多图、多卖点或多段议程 | 用分区、网格或共同边线区隔信息，版心、栏距和基线随内容设定。 | 同类图像的裁切和色调可统一。需要强调某幅图时，用大小、景别或跨栏明确其角色。 |
| 运动、速度或方向性强 | 让主体或部分辅助元素沿斜线运动，其他文字保持可阅读的方向。 | 主体的视线、朝向或动作引向内容，倾斜与切边保留清楚的阅读节奏。 |

## 要提高层级或空间感时

- **层级**决定读者先辨认、再读到哪些信息。先移除会争抢注意的装饰，再用大小、字重、位置、光暗或色彩拉开差别。处理一整块文字时，可以先让各段左边或中心有共同参照，再用行内、段内和段间距离表达从属。需要强调一句话时，只提高那一句的视觉重量。
- **空间感**取决于前后关系。由轻到重试主体周围的空白、前后物体的尺度和遮挡、明暗或色彩的进退、带透视的实景。冷暖、纯度和明暗的效果受相邻颜色影响，要在整张图里比对。对高频信息保留平稳的文字区，清晰度优先留给主体和关键字。
- **照片合成**先画主体、承托面和背景的位置。选素材时核对机位、透视、尺度、光向和画质。粗合成通顺后再处理色温、明暗、边缘、接触阴影与投影。接触处可以更实，投影朝背离光源的方向延伸，边缘虚实随距离和光源变化。合理遮挡可以消化接缝，交付前仍要核查可见轮廓及识别细节。
- **用装饰收尾**时，可从主体的形、色或主题里提取点、线、框、图标或肌理。框的主要作用可以是标出一个信息组。斜切可以表现动势，背景大字可以形成形状，相关图标可以帮助扫读。只有在承担实际作用时才添加。用得到的外文应有准确语义，作为补充阅读时按次要层级排版。
